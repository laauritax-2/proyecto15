Necesitas tener Node.js instalado y conexión a internet para descargar React y Vite.

ARCHIVOS
- index.html: contiene el espacio donde se muestra React.
- src/main.jsx: contiene las tarjetas, los componentes y la lógica.
- src/style.css: contiene los estilos de la aplicación.
- package.json: indica las dependencias y comandos del proyecto.

COMO FUNCIONA
- Las preguntas y respuestas están guardadas en un arreglo llamado tarjetas.
- El componente FlashCard muestra una tarjeta.
- useState guarda el número de tarjeta y si está volteada.
- El botón de la tarjeta cambia entre pregunta y respuesta.
- Los botones Anterior y Siguiente permiten recorrer las tarjetas.
- La barra muestra el progreso de la tarjeta actual.

REQUISITOS DEL PDF
- Tarjetas predefinidas con preguntas y respuestas.
- Barra de progreso.
- Ver una tarjeta a la vez y voltearla para mostrar la respuesta.
- Navegación para recorrer las tarjetas.
